FORMA 0.3.0 - GLM DESIGN STUDIO
Build date: 15 October 2026

Application source, configuration templates, tests and documentation for
Forma 0.3.0, plus bundled design assets:
- assets/fonts: 11 open-source font families (SIL Open Font License 1.1,
  from Fontsource; latin subset, variable weight). See assets/fonts/OFL.txt.
- assets/icons/lucide.json: 1,890 Lucide icons (ISC licence).
- assets/kit/forma-kit.css: Forma's component library.

The portable Windows ZIP built by scripts/package-windows.cjs also contains:
- runtime/node.exe and runtime/LICENSE: Node.js v24.18.0 for Windows x64,
  downloaded from nodejs.org and verified against its SHASUMS256.txt.
- node_modules: production dependencies pinned by package-lock.json
  (docx, pptxgenjs, playwright, sanitize-html and their dependencies),
  installed with npm ci --ignore-scripts. Upstream licences stay inside each
  package.
- SHA256SUMS.txt covering every file in the package.

Not included: GLM model weights, API credentials, a browser (installed
Edge/Chrome is used), LibreOffice, Poppler, .env, databases or projects.
No package downloads are performed by the launch scripts.
