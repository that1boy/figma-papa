FORMA 0.3.0 - SETUP ON THE ORGANISATION'S WINDOWS COMPUTER

WHERE TO FOLLOW THESE INSTRUCTIONS
These steps are for the person working on the organisation's Windows PC where
Forma will run. "This computer" and "localhost" mean that PC, not the GLM
model server. Forma is a portable app: extract, configure, start. The GLM
model is a separate internal API; it is not installed here.

WHAT YOU NEED
- Windows x64, a writable folder (for example Documents\Forma), permission to
  run Node.js under company policy, Edge or Chrome, and network access from
  this PC to the organisation's GLM endpoint.
- One of:
  a) forma-windows-x64-0.3.0.zip, built with
     glm-design-pilot\scripts\package-windows.cjs on any internet-connected
     machine (includes Node.js and all dependencies), or
  b) an existing Forma 0.1.x/0.2.x portable installation plus this
     repository's glm-design-pilot-windows-x64\glm-design-pilot folder.
     0.3.0 adds no npm dependencies, so the existing runtime\node.exe and
     node_modules keep working.

NEW INSTALLATION (option a)
1. Copy forma-windows-x64-0.3.0.zip to this PC and use Extract All.
   Optional: compare the ZIP with its .sha256 file.
2. Open the extracted glm-design-pilot folder and run 01-configure.cmd.
   It creates .env with a random login password and secrets, then opens it.
3. To explore first, keep MODEL_MODE=demo (fixed examples, no model calls).
   For real generation set:
       MODEL_MODE=glm
       GLM_BASE_URL=http://YOUR-INTERNAL-HOST:8000/v1
       GLM_MODEL=EXACT-DEPLOYED-MODEL-ID
       GLM_API_KEY=YOUR-KEY-IF-REQUIRED
   GLM_BASE_URL is the API prefix; Forma appends /chat/completions. Use the
   exact model ID your inference team gives you. Do not guess credentials.
4. Save .env and run 02-start.cmd. Open http://127.0.0.1:8080 and log in with
   APP_PASSWORD from .env. Use Check connection, then try a small project.

UPGRADING AN EXISTING INSTALLATION (option b)
1. Stop Forma. Copy the whole existing glm-design-pilot folder to a new
   folder as the 0.3.0 copy; keep the original as a stopped backup.
2. Copy the CONTENTS of this repository's
   glm-design-pilot-windows-x64\glm-design-pilot folder over the new copy,
   replacing program files. Keep runtime\node.exe, node_modules, .env and
   data. Do not create glm-design-pilot\glm-design-pilot nesting.
3. Confirm package.json says 0.3.0, then run 02-start.cmd. Startup migrates
   the database (new columns and tables only; saved work is kept).
   Never run two versions against the same data folder.

NEW GLM SETTINGS (all optional; defaults shown in .env.windows.example)
  GLM_STREAM=true          live progress while GLM writes
  GLM_VISION=auto          send images; fall back to text-only if refused
  GLM_MAX_IMAGES=8         images per request
  GLM_PARALLEL=3           screens built at the same time
  GLM_PIPELINE=staged      plan, build screens in parallel, then review
  GLM_EFFORT_REVIEW=low    reasoning effort for the review stage
See glm-design-pilot\README.md and docs\GLM-SERVING.md for the full list.

OPTIONAL
- Forma.exe launcher: put forma-launcher-1.0.0-20261005-201153\Forma.exe next
  to 02-start.cmd. Needs .NET Framework 4.5+ and company approval to run.
- LibreOffice + Poppler enable native Office PDF/page rendering. Editable
  PPTX/DOCX export works without them.

TROUBLESHOOTING
- Run 03-diagnostics.cmd. It checks Node, dependencies, bundled assets,
  settings, browser and LibreOffice detection without contacting the model.
- If a port is busy, set PORT and RENDER_PORT in .env to unused values.
- Corporate HTTPS CA: set NODE_EXTRA_CA_CERTS=C:/path/company-ca.pem in .env.
- Do not bypass company execution policies.
